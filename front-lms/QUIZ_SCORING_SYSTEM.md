# ระบบการให้คะแนนแบบทดสอบ (Quiz Scoring System)

## สรุปการเปลี่ยนแปลง

ระบบการให้คะแนนได้รับการปรับปรุงให้รองรับ **การให้คะแนนตามสัดส่วน (Proportional Scoring)** สำหรับ:

1. **Multiple Choice** - ข้อที่มีคำตอบถูกมากกว่า 1 ข้อ
2. **Matching** - ข้อจับคู่ที่มีหลายคู่

---

## 🎯 ประเภทคำถามและวิธีการให้คะแนน

### 1. Multiple Choice (ปรนัย)

#### คำตอบเดียว (Single Answer)
- ตอบถูก = ได้เต็ม
- ตอบผิด = ได้ 0

#### หลายคำตอบ (Multiple Answers) ✨ ใหม่
**สูตรคะแนน:**
```
คะแนนที่ได้ = [(เลือกถูก / คำตอบที่ถูกทั้งหมด) - (เลือกผิด / คำตอบที่ถูกทั้งหมด)] × คะแนนเต็ม
```

**ตัวอย่าง:** ข้อสอบ 10 คะแนน มีคำตอบที่ถูก 4 ข้อ (A, B, D, E)

| นักเรียนเลือก | เลือกถูก | เลือกผิด | คะแนนที่ได้ | คำนวณ |
|--------------|----------|----------|-------------|-------|
| A, B, D, E | 4 | 0 | **10.00** | (4/4 - 0/4) × 10 = 10 |
| A, B, D | 3 | 0 | **7.50** | (3/4 - 0/4) × 10 = 7.5 |
| A, B | 2 | 0 | **5.00** | (2/4 - 0/4) × 10 = 5 |
| A, B, C | 2 | 1 | **2.50** | (2/4 - 1/4) × 10 = 2.5 |
| A, B, C, F | 2 | 2 | **0.00** | (2/4 - 2/4) × 10 = 0 |
| C, F | 0 | 2 | **0.00** | (0/4 - 2/4) × 10 = -5 → 0 |

**หมายเหตุ:** คะแนนต่ำสุดคือ 0 (ไม่ติดลบ)

---

### 2. Matching (จับคู่)

**สูตรคะแนน:**
```
คะแนนที่ได้ = (จำนวนคู่ที่จับคู่ถูก / จำนวนคู่ทั้งหมด) × คะแนนเต็ม
```

**ตัวอย่าง:** ข้อสอบ 6 คะแนน มี 3 คู่ที่ต้องจับ

| คู่ที่จับถูก | คะแนนที่ได้ | คำนวณ |
|-------------|-------------|-------|
| 3/3 คู่ | **6.00** | (3/3) × 6 = 6 |
| 2/3 คู่ | **4.00** | (2/3) × 6 = 4 |
| 1/3 คู่ | **2.00** | (1/3) × 6 = 2 |
| 0/3 คู่ | **0.00** | (0/3) × 6 = 0 |

---

### 3. Fill in the Blank (เติมคำ)

- ตรงตามเฉลย (case-insensitive) = ได้เต็ม
- ไม่ตรง = ได้ 0
- ไม่ระบุเฉลย = รอครูตรวจ

---

### 4. Essay (อัตนัย)

- **ต้องตรวจด้วยตนเอง** โดยครูผู้สอน
- สามารถระบุแนวทางเฉลยไว้สำหรับอ้างอิงในการตรวจ

---

## 🔧 การใช้งานในโค้ด

### ฟังก์ชันหลัก: `calculateQuestionScore`

```typescript
import { calculateQuestionScore } from "@/lib/quizScoring";

const result = calculateQuestionScore(question, studentAnswer);

// result = {
//   score: number,           // คะแนนที่ได้
//   isCorrect: boolean | null,  // true = ถูกเต็म, false = ผิด, null = รอตรวจ
//   isPartial: boolean,      // true = ถูกบางส่วน
//   studentAnswerText: string,  // คำตอบของนักเรียนในรูปแบบข้อความ
//   correctAnswerText: string,  // เฉลยในรูปแบบข้อความ
//   detailText?: string      // รายละเอียดเพิ่มเติม เช่น "ถูก 3/4, เลือกผิด 1"
// }
```

### Helper Functions

```typescript
// ดึงเลขที่คำตอบถูกทั้งหมด (รองรับ correctIndex และ correctIndices)
import { getQuestionCorrectIndices } from "@/lib/quizScoring";
const correctIndices = getQuestionCorrectIndices(question); // [0, 2, 3]

// แปลงคำตอบนักเรียนเป็น array
import { getStudentSelectedIndices } from "@/lib/quizScoring";
const selected = getStudentSelectedIndices(answer); // [0, 1, 2]
```

## 📁 ไฟล์ที่เกี่ยวข้อง

### Core Files
- **`lib/quizScoring.ts`** - ฟังก์ชันคำนวณคะแนนหลัก ✨ ใหม่
- **`app/context/UserContext.tsx`** - เพิ่ม `correctIndices?: number[]` และ `answers` รองรับ `number[]`

### Student Components
- **`app/student/_components/QuizPlayer.tsx`** - หน้าทำข้อสอบของนักเรียน (อัปเดตการคำนวณคะแนน)
- **`app/student/_components/QuizQuestionRenderer.tsx`** - แสดงคำถามและรับคำตอบ (รองรับหลายคำตอบ)

### Teacher Components
- **`app/teacher/_components/QuizEditorPanel.tsx`** - หน้าสร้าง/แก้ไขข้อสอบ
- **`app/teacher/_components/QuestionEditor.tsx`** - แก้ไขคำถามแต่ละข้อ (รองรับเลือกหลายคำตอบถูก)
- **`app/teacher/_components/QuizReviewPage.tsx`** - หน้าตรวจข้อสอบของครู

## 🎨 UI/UX สำหรับนักเรียน

### หน้าทำข้อสอบ
- ข้อที่มีคำตอบถูกหลายข้อจะแสดง:
  - แบนเนอร์สีน้ำเงิน: **"☑️ ข้อนี้มีคำตอบที่ถูกต้อง X ข้อ (เลือกคำตอบที่ถูกต้องทั้งหมด)"**
  - ข้อความเล็ก: **"*ให้คะแนนตามสัดส่วน"**
  - ใช้ checkbox แทน radio button

### หน้าดูเฉลย
- แสดงสถานะ:
  - ✓ **ถูกต้อง (เต็ม)** - สีเขียว
  - ⚡ **ถูกต้องบางส่วน** - สีส้ม
  - ✗ **ไม่ถูกต้อง** - สีแดง
- แสดงรายละเอียด: `"ถูก 3/4, เลือกผิด 1, ขาด 0"`

### ข้อจับคู่
- แบนเนอร์: **"* ให้คะแนนตามสัดส่วนคู่ที่จับคู่ถูกต้อง"**
- แสดงรายละเอียด: `"จับคู่ถูก 2 จาก 3 คู่"` และ `"ถูก 2/3 คู่"`

---

## 🎓 UI/UX สำหรับครู

### หน้าสร้างข้อสอบ
- สามารถคลิกปุ่ม **"✓ คำตอบที่ถูกต้อง"** ได้หลายข้อ
- แสดงสรุปเฉลย: **"เฉลยข้อที่ถูกต้อง: A C D"**
- แสดงข้อความ: **"⭐ มี 3 ข้อถูกต้อง (ให้คะแนนตามสัดส่วนที่เลือกถูก)"**

### หน้าตรวจข้อสอบ
- แสดงคะแนนที่ระบบคำนวณอัตโนมัติ (รองรับทศนิยม)
- สามารถปรับคะแนนแต่ละข้อได้ (0 ถึงคะแนนเต็มของข้อนั้น)
- แสดงรายละเอียดการตอบของนักเรียนพร้อมเฉลย

---

## 🔄 Backward Compatibility

ระบบยังคงรองรับข้อสอบเก่าที่ใช้ `correctIndex` (คำตอบเดียว):
- ถ้ามี `correctIndices` → ใช้ค่านี้
- ถ้าไม่มี แต่มี `correctIndex` → แปลงเป็น `[correctIndex]`
- ถ้าไม่มีทั้งสอง → ใช้ `[0]` เป็นค่า default

## ✅ สรุปคุณสมบัติ

✨ **ระบบให้คะแนนตามสัดส่วน**
- Multiple choice หลายคำตอบ
- Matching แบบบางส่วน

📊 **การแสดงผล**
- แสดงสถานะ: เต็ม / บางส่วน / ผิด
- รายละเอียดการตอบและเฉลย
- คะแนนที่ได้ / คะแนนเต็ม

🔧 **ความยืดหยุ่น**
- รองรับตัวเลือกได้มากกว่า 4 ข้อ
- รองรับคู่จับคู่ได้มากกว่า 2 คู่
- ครูสามารถปรับคะแนนได้ในภายหลัง

🎯 **ความยุติธรรม**
- ตอบถูกบางส่วนได้คะแนนตามสัดส่วน
- เลือกผิดจะถูกหักคะแนน
- จับคู่ถูกบางคู่ได้คะแนนตามสัดส่วน

## 📝 ตัวอย่างการใช้งาน

### ครูสร้างข้อสอบ
1. เลือกประเภทคำถาม "ปรนัย"
2. เพิ่มตัวเลือก 4-6 ข้อ (หรือมากกว่า)
3. **คลิกเลือกคำตอบที่ถูกได้หลายข้อ** (เช่น A, C, D)
4. ระบบจะแสดง "⭐ มี 3 ข้อถูกต้อง (ให้คะแนนตามสัดส่วน)"
5. บันทึกข้อสอบ

### นักเรียนทำข้อสอบ
1. เห็นแบนเนอร์ "ข้อนี้มีคำตอบที่ถูกต้อง 3 ข้อ"
2. สามารถเลือกหลายช้อยส์ได้ (แสดง checkbox)
3. ส่งข้อสอบ → ระบบคำนวณคะแนนอัตโนมัติ

### ครูตรวจข้อสอบ
1. เห็นคะแนนที่ระบบคำนวณให้ (เช่น 7.5 / 10)
2. เห็นรายละเอียด "ถูก 3/4, เลือกผิด 1"
3. สามารถปรับคะแนนได้ตามดุลยพินิจ
